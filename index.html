      About StaffQuest

      StaffQuest is a gamified training and motivation prototype for restaurant employees, built for a software engineering project.

      Key demo tips:

      • Use the Employee tab to show XP, levels, quests, and achievements.
      • Use the Manager tab (PIN 1234) to show team overview and quest manager.
      • All data is stored locally in this browser only using localStorage.
      • Reset demo data from the Data Controls card in the Manager view.

      This version focuses on UX, gamification, and local prototypes. A future version could plug into a real backend for multi-location deployments.
